I. YÊU CẦU HỆ THỐNG & CÔNG NGHỆ SỬ DỤNG
--------------------------------------------------------------------------------
1. Công nghệ sử dụng:
   - Backend: Node.js (Express.js)
   - Cơ sở dữ liệu: Microsoft SQL Server (kết nối qua mssql / msnodesqlv8)
   - Database Fallback: SQLite (tự động chuyển đổi nếu chưa cấu hình SQL Server)
   - Frontend: HTML5, CSS3, JavaScript (Single Page Application - SPA)
   - Xác thực: JWT (JSON Web Token)

2. Đòi hỏi môi trường cài đặt:
   - Node.js version >= 16.x (Khuyên dùng v18+)
   - Microsoft SQL Server 2016 trở lên (SQL Express hoặc Server chính thức)
   - Trình duyệt Web hiện đại (Google Chrome, Microsoft Edge, Firefox, Brave...)

================================================================================
II. HƯỚNG DẪN CÀI ĐẶT
--------------------------------------------------------------------------------
Bước 1: Khởi tạo Cơ sở dữ liệu trong SQL Server
------------------------------------------------
1. Mở Microsoft SQL Server Management Studio (SSMS).
2. Kết nối vào SQL Server Instance trên máy của bạn (Ví dụ: localhost\SQLEXPRESS).
3. Mở file script SQL có sẵn tại: database/schema_sqlserver.sql
4. Thực thi (Execute - F5) toàn bộ script để tạo Database `CosmeticsCRM_DB`, các bảng và dữ liệu mẫu.

Bước 2: Cấu hình biến môi trường (.env)
---------------------------------------
1. Mở file `.env` ở thư mục gốc của dự án.
2. Kiểm tra và chỉnh sửa các tham số kết nối cho đúng với SQL Server trên máy bạn:

   DB_TYPE=mssql
   DB_SERVER=localhost\SQLEXPRESS    # Thay đổi thành Tên Server của bạn (ví dụ: PHAZT\SQLEXPRESS)
   DB_DATABASE=CosmeticsCRM_DB
   PORT=3000
   JWT_SECRET=cosmetics_crm_secret_2026

Bước 3: Cài đặt các gói thư viện Node.js
----------------------------------------
Mở Terminal / Command Prompt tại thư mục dự án và chạy lệnh:

   npm install

Lệnh trên sẽ cài đặt các gói cần thiết: express, mssql, msnodesqlv8, dotenv, jsonwebtoken, bcryptjs, sql.js.

Bước 4: Khởi chạy phần mềm
--------------------------
Tại Terminal, gõ lệnh:

   npm start

Khi màn hình Terminal hiển thị:
   ✅ Đã kết nối thành công tới Microsoft SQL Server: CosmeticsCRM_DB
   🚀 Server đang chạy: http://localhost:3000

Mở trình duyệt web và truy cập địa chỉ: http://localhost:3000

IV. HƯỚNG DẪN SỬ DỤNG THEO VÀI TRÒ (PHÂN RÃ CHỨC NĂNG)
--------------------------------------------------------------------------------
1. Giao diện ADMIN (Quản trị hệ thống):
   - Giao diện Admin được thiết kế tách biệt hoàn toàn.
   - Tìm kiếm & Lọc nâng cao: Tìm kiếm theo tên sản phẩm, nhà cung cấp, loại sản phẩm, trạng thái ra mắt.
   - Quản lý tài khoản (CRUD): Xem danh sách tài khoản, phân quyền (ADMIN, MANAGER, CUSTOMER), khóa/mở khóa tài khoản.
   - Quản lý Danh mục Sản phẩm & Nhà cung cấp: Thêm mới, chỉnh sửa, cập nhật số lượng tồn kho.

2. Giao diện MANAGER (Quản lý Cửa hàng & CRM):
   - Quản lý Khách hàng: Thêm khách hàng mới, khóa/mở khóa tài khoản khách hàng.
   - Thống kê & Báo cáo CRM: Xem biểu đồ/báo cáo phân tích tỷ lệ độ tuổi khách hàng, sở thích làm đẹp (chăm sóc da, trang điểm, chống lão hóa...), loại da.
   - Khảo sát thị hiếu sản phẩm mới:
     * Tạo bài khảo sát mới kèm các câu hỏi (Trắc nghiệm, Đánh giá sao, Ý kiến).
     * Gửi chiến dịch khảo sát tới danh sách khách hàng.
     * Thống kê kết quả phản hồi của khách hàng đối với dòng sản phẩm mới.
   - Tiếp nhận Phản hồi: Xem danh sách phản hồi từ khách hàng và gửi câu trả lời trực tiếp.

3. Giao diện CUSTOMER (Khách hàng):
   - Đăng ký / Đăng nhập: Đăng ký tài khoản khách hàng mới kèm thông tin độ tuổi, loại da, sở thích mỹ phẩm.
   - Quản lý thông tin cá nhân: Cập nhật thông tin hồ sơ làm đẹp.
   - Gửi Phản hồi: Đánh giá chất lượng sản phẩm (1-5 sao) và gửi bình luận.
   - Làm bài Khảo sát: Nhận các bài khảo sát sản phẩm mới từ cửa hàng và điền ý kiến đánh giá.

V. HƯỚNG DẪN SAO LƯU VÀ PHỤC HỒI CƠ SỞ DỮ LIỆU (BACKUP & RESTORE)
--------------------------------------------------------------------------------
File kịch bản SQL sao lưu & phục hồi nằm tại: database/backup_restore.sql

1. Sao lưu Cơ sở dữ liệu (Backup):
   - Mở SSMS, chọn New Query và thực thi các câu lệnh backup trong file database/backup_restore.sql:
   - Full Backup:
     BACKUP DATABASE CosmeticsCRM_DB TO DISK = 'C:\Backup\CosmeticsCRM_Full.bak' WITH FORMAT, INIT, NAME = 'Full Backup CosmeticsCRM';
   - Differential Backup (Sao lưu vi sai định kỳ):
     BACKUP DATABASE CosmeticsCRM_DB TO DISK = 'C:\Backup\CosmeticsCRM_Diff.bak' WITH DIFFERENTIAL, NAME = 'Diff Backup CosmeticsCRM';

2. Phục hồi Cơ sở dữ liệu (Restore test case):
   - Kịch bản phục hồi khi xảy ra sự cố (Giả lập mất dữ liệu hoặc lỗi CSDL):
     ALTER DATABASE CosmeticsCRM_DB SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
     RESTORE DATABASE CosmeticsCRM_DB FROM DISK = 'C:\Backup\CosmeticsCRM_Full.bak' WITH REPLACE;
     ALTER DATABASE CosmeticsCRM_DB SET MULTI_USER;

VI. CÁC LỖI KẾT NỐI DATABASE THƯỜNG GẶP VÀ CÁCH KHẮC PHỤC CHUẨN (NEW)
--------------------------------------------------------------------------------
Khi clone mã nguồn từ GitHub về máy cá nhân (Local), hệ thống có thể gặp một số 
lỗi môi trường do sự khác biệt về driver và cấu hình SQL Server. Dưới đây là 3 
trường hợp lỗi phổ biến nhất và cách xử lý dứt điểm:

1. Lỗi hệ thống trơ trơ, không nhận file .env mới chỉnh sửa
   - Triệu chứng: Terminal hiển thị cấu hình từ máy của người cũ (Ví dụ: PHAZT\SQLEXPRESS) 
     mặc dù bạn đã sửa đổi file .env.
   - Nguyên nhân: File cấu hình thực tế `.env` nằm trong danh sách chặn của Git (.gitignore) 
     nên không có sẵn khi clone code về. Bạn chỉ đang chỉnh sửa trên file mẫu `.env.example`.
   - Cách khắc phục:
     * Bước 1: Click chuột phải vào file `.env.example` -> Chọn Copy.
     * Bước 2: Paste ngay tại thư mục gốc ngoài cùng (ngang hàng package.json).
     * Bước 3: Đổi tên file vừa paste chính xác thành `.env` (Xóa đuôi .example đi).
     * Bước 4: Nhấn Ctrl + C để tắt Server cũ, chạy lại `npm start` để hệ thống nạp lại.

2. Lỗi vấp Driver kết nối hệ thống (Data source name not found)
   - Triệu chứng: Terminal báo lỗi màu vàng: 
     "⚠️ Không thể kết nối SQL Server, chuyển sang SQLite dự phòng: [Microsoft][ODBC Driver Manager] Data source name not found..."
   - Nguyên nhân: Thư viện kết nối mạng (`msnodesqlv8`) kén chọn và bắt buộc Windows phải 
     có bộ thông dịch driver tương ứng. Máy cá nhân mới cài đặt thường thiếu driver này.
   - Cách khắc phục (Chọn 1 trong 2 cách):
     * Cách 1 (Khuyên dùng): Tải bộ cài đặt chính thức `ODBC Driver 18 for SQL Server` 
       từ trang chủ Microsoft (chọn bản Windows x64 phù hợp). Cài đặt xong, TẮT HẲN VS Code 
       và mở lại để Windows nhận diện Driver mới.
     * Cách 2 (Sửa trực tiếp trong code): Mở file cấu hình kết nối database trong dự án 
       (nơi chứa hàm `initSqlServer()`), tìm đến đoạn chuỗi kết nối (Connection String) 
       và sửa Driver từ `{ODBC Driver 18 for SQL Server}` thành `{SQL Server}` để ép 
       Node.js sử dụng bộ driver mặc định luôn có sẵn 100% trên mọi máy Windows.

3. Lỗi Connection Timeout (Bị treo vô hạn ở dòng "Đang kết nối...")
   - Triệu chứng: Ứng dụng đứng im vĩnh viễn ở dòng log "Đang kết nối Microsoft SQL Server..." 
     và không báo thành công hay thất bại.
   - Nguyên nhân: Sai lệch phiên bản cài đặt SQL Server. Mã nguồn mặc định trỏ vào 
     bản thu nhỏ `.\SQLEXPRESS`, nhưng máy bạn có thể đang cài bản SQL Server chuẩn 
     (Default Instance) chạy ngầm dưới tên `MSSQLSERVER` hoặc `localhost`.
   - Cách khắc phục:
     * Bước 1: Kiểm tra Service trong Windows: Nhấn Windows + R -> gõ `services.msc`. 
       Tìm dịch vụ `SQL Server (MSSQLSERVER)` hoặc `SQL Server (SQLEXPRESS)`. Đảm bảo trạng 
       thái của nó đang là "Running".
     * Bước 2: Sửa file `.env`: 
       Nếu máy bạn chạy bản `MSSQLSERVER`, hãy sửa dòng `DB_SERVER=.\SQLEXPRESS` thành 
       `DB_SERVER=localhost` (hoặc chỉ để dấu chấm `.`).
     * Bước 3: Bật cổng mạng kết nối cho SQL Server: Mở phần mềm `SQL Server Configuration Manager` 
       trên máy -> Vào mục `Protocols for SQLEXPRESS/MSSQLSERVER` -> Bật `TCP/IP` sang `Enabled`. 
       Tại tab IP Addresses, kéo xuống mục `IPAll` và điền TCP Port là `1433`. Tiến hành 
       Restart lại dịch vụ SQL Server để áp dụng.
